字段映射配置界面

如何配置外部字段到本地字段的映射关系?

A

表格编辑模式(推荐)

类似Excel的表格,每行一个映射,直观易用。适合批量配置。

字段映射 - 教职工数据库
外部字段 本地字段 映射方式 映射规则 操作
- 删除
- 删除
删除
B

表单卡片模式

每个映射一个独立卡片,展开配置详情。适合映射项较少、需要详细说明的场景。

字段映射 - 教职工数据库
employee_id → username 直接映射

外部员工的工号直接映射为登录用户名

user_type → role 值映射

teacher → 1, admin → 10, student → 1

C

向导模式

分步骤引导配置: 选择外部表 → 预览字段 → 逐一映射 → 确认。适合首次配置。

字段映射向导
1.选择表 → 2.映射字段 → 3.确认
