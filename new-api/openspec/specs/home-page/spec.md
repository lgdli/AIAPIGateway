## MODIFIED Requirements

### Requirement: Generic home page content
The system SHALL display generic placeholder content on the home page by default.

#### Scenario: No GitHub button on home page
- **WHEN** user visits the home page
- **THEN** no button linking to GitHub repository is displayed

#### Scenario: Generic hero text
- **WHEN** user visits the home page
- **THEN** the hero section displays generic AI gateway messaging without project-specific branding
