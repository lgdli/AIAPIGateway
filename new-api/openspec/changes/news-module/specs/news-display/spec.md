# Spec: news-display

## Summary

首页新闻卡片展示 + 详情页，用户可浏览新闻、按分类筛选、点击查看详情。

---

## UI Specification

### 首页新闻区域

**Location**: Banner 下方独立区域

**Layout**:
```
┌─────────────────────────────────────────────────────────────────┐
│  新闻公告                              [全部][系统][功能][公告]  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│   │ 封面图   │  │ 封面图   │  │ 封面图   │  │ 封面图   │       │
│   │ 16:9    │  │ 16:9    │  │ 16:9    │  │ 16:9    │       │
│   ├──────────┤  ├──────────┤  ├──────────┤  ├──────────┤       │
│   │ 标题     │  │ 标题     │  │ 标题     │  │ 标题     │       │
│   │ 摘要...  │  │ 摘要...  │  │ 摘要...  │  │ 摘要...  │       │
│   ├──────────┤  ├──────────┤  ├──────────┤  ├──────────┤       │
│   │📅 01-15  │  │📅 01-10  │  │📅 01-05  │  │📅 01-01  │       │
│   │🏷️ 系统  │  │🏷️ 功能  │  │🏷️ 公告  │  │🏷️ 功能  │       │
│   └──────────┘  └──────────┘  └──────────┘  └──────────┘       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**Card Fields**:
| Field | Type | Required | Notes |
|-------|------|----------|-------|
| image | string | No | 封面图 URL，无图时显示占位 |
| title | string | Yes | 最大 200 字符，超出省略 |
| summary | string | No | 最大 500 字符，超出省略 |
| publishDate | datetime | Yes | 显示相对时间 + 绝对时间 |
| category | enum | Yes | 系统公告/功能更新/价格调整/通知 |

**Filter Tabs**:
- 默认选中"全部"
- 点击分类标签筛选对应分类
- 筛选后重新加载 4 条

**Behavior**:
- 点击卡片 -> 跳转 /news/:id
- 置顶新闻始终显示在第一位（无论发布时间）
- 默认显示 4 条已发布新闻
- 响应式：移动端 1 列，平板 2 列，桌面 4 列

---

### 新闻详情页

**Route**: /news/:id

**Layout**:
```
┌─────────────────────────────────────────────────────────────────┐
│  [返回] ← 返回首页                                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                     封面图（可选）                        │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  标题                                                          │
│  📅 2024-01-15 10:00    🏷️ 系统公告                            │
│                                                                 │
│  ───────────────────────────────────────────────────────────   │
│                                                                 │
│  正文内容（Markdown 渲染）                                      │
│                                                                 │
│  ...                                                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**Fields**:
| Field | Type | Notes |
|-------|------|-------|
| title | string | 页面标题 |
| image | string | 封面图（可选） |
| content | string | Markdown 格式，渲染为 HTML |
| publishDate | datetime | 显示绝对时间 |
| category | enum | 分类标签 |

**SEO**:
- 页面 title: {title} - AI Gateway
- meta description: 使用 summary 或 content 前 160 字符

## API Specification

### GET /api/news

获取公开新闻列表（仅已发布）

**Query Params**:
| Param | Type | Default | Notes |
|-------|------|---------|-------|
| category | string | "" | 空为全部 |
| limit | int | 4 | 返回条数 |
| offset | int | 0 | 分页偏移 |

**Response**:
```json
{
  "success": true,
  "message": "",
  "data": [
    {
      "id": 1,
      "title": "系统升级通知",
      "summary": "系统将于...",
      "image": "https://...",
      "category": "system",
      "pinned": true,
      "publish_date": "2024-01-15T10:00:00Z"
    }
  ]
}
```

**Sorting**: pinned DESC, publish_date DESC

---

### GET /api/news/:id

获取新闻详情

**Response**:
```json
{
  "success": true,
  "message": "",
  "data": {
    "id": 1,
    "title": "系统升级通知",
    "summary": "系统将于...",
    "content": "## 详细内容\n\n...",
    "image": "https://...",
    "category": "system",
    "publish_date": "2024-01-15T10:00:00Z"
  }
}
```
